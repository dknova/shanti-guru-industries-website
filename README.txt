SHANTI GURU INDUSTRIES LIMITED - WEBSITE

Open index.html to view the site.

POLICIES AND CODE OF CONDUCT
These documents now open inside the site (View all policies / Code of Conduct under Investors Desk).
The PDF files must sit in these folders, next to index.html:
  documents/policies/          (P1.pdf ... P13.pdf, dividend-policy.pdf, etc.)
  documents/code-of-conduct/   (COC1.pdf, COC2.pdf)

To fetch them from the old website automatically:
  Windows:      double-click download-documents.bat
  Mac / Linux:  python3 download-documents.py
(Both need an internet connection and only need to be run once.)
Or download each PDF by hand from the old site and save it with the same file name.
